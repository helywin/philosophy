# M.福柯

- 全影监视监狱，精神病，诊所的形成
- 话语理论 -> 商谈 -> 社会是权力结构，政治，文化，经济 -> 社会权利由话语产生
- 讨论近代西方思想，怎样用话语制造思想
- 《疯癫史》：文艺复兴，理性，终极价值，疯癫被排除在理性范围外，话语制造出一个界限，对整个社会理性化破坏，精神病院，中世纪正常 -> 被排除成另类，又要去拯救。理性霸权化的历史。正常社会中隔离出来不正常的空间。理性成为对所有人监视的权力
- 《新历史主义》：西方的，城市的，白人种的，男性的，理性的，科学的，后殖民主义，理性霸权化话语，其他文明被边缘化。如鲁滨逊漂流记
- 分析话语后的权力主义和意识形态
- 进步论历史观，人类由低到高的进步序列，时间越靠后越文明。每一个个体都是一个阶段，一个台阶（信仰不同）。把人类全部历史视作达到辉煌顶点的一，人类是目的的，目的论。所有的作恶为了实现目的而变得正常。为了不杀人而杀人
