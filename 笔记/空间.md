# 空间

- [[对象]] 的大小，形状以及相互之间的关系可以确认，或是可以被确定下来
- 确定性的 [[表象]]
- 没有空间无法表象外部事物，外部对象，也无法表象外部对象和我们内心之间的区别
- [[形而上学]] 的阐明
    - 1. 空间不是什么从外部经验中抽引出来的 [[经验性]] 的 [[概念]]
        - 先天的概念
        - 空间 [[表象]] 不能从外部 [[现象]] 的关系中由 [[经验]] 借来，相反，这种外部经验本身只有通过上述表象才是可能的
    - 2. 空间是一个作为一切 [[外直观|外部直观]] 之基础的必然的先天 [[表象]]
        - 对于空间不存在，我们永远不能形成一个 [[表象]]
    - 3. 空间绝不是关于 [[一般事物]] 的关系的推论的概念，或如人们所说， [[普遍的概念]] ，而是一个 [[纯直观]]
        - 多个空间能从一个空间中分割出来，但都是同一个空间的不同部分，跟唯一的空间没有区别
        - 一般诸多空间的普通概念都是基于对它的限制性[^1]
    - 4. 空间被表象为一个无限的给予量
        - 每一个 [[概念]] 都设想为一个被包含在无限数量的各种可能 [[表象]] 之中（作为共同性标志）、因而将这些表象都包含于其下的表象
        - 概念不能设想为所有的 [[表象]] 都包含于其中
        - 空间的原始 [[表象]] 是 [[纯直观|先天直观]] ，而不是 [[概念]]
    - [^1]: [[范畴]] 里面质的概念
- [[先验阐明]]
    - 几何知识确实是从空间概念中推出来的
        - 现实性：举例子可以证明
        - 可能性：空间必须是直观而不是概念，从概念中不能引出超出概念的命题，也就是只能引出分析命题。但是几何学里面发生的是先天综合命题
- [[经验性]] 的实在性
    - 空间对一切外部 [[现象]] 具有普遍的有效性，而且是“ [[客观]] ”的有效性
- [[先验的观念性]]
    - 从先验的角度看，空间不是 [[物自体|自在之物]] 的属性，而只能是主观中的观念
