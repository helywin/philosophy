# 弗洛伊德

- 《梦的解析》，《精神分析引论》，《图腾与禁忌》，《性学三论》
- 医生，看病的时候要解决别人的心理问题
- 核心：意识，无意识，非理性，梦，性本能，本我，自我，超我，儿童情欲，禁忌，压抑，升华转移，白日梦，俄狄浦斯情结，快乐原则，死本能
- 理性主义文化危机，症候分析方法
    - 梵高，艺术家就是正常人与非正常人之间。诗人——不符合理性，受制于潜意识，天才就是非理性，成年时代出现问题与性有关。纳入父权道德体系。欲望没被实现，做梦，或通过艺术。莎士比亚要表达恋母情结，父亲死了，假的国王占据了父亲。弑父与弑君
- 本我：非理性，欲望，性本能。
- 自我：展现
- 超我：道德体系
- 压抑反抗 -> 形成自我
- 晚年思考人类文明，图腾：转移和升华潜意识，限制性本能
- 症候分析，关注反常的东西（一个人的反常的时候）
